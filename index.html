✦ Firebase

로그인과 Firestore 동기화

Firebase Hosting은 사용하지 않고, GitHub Pages는 화면 담당, Firebase Authentication과 Firestore는 로그인·데이터 동기화 담당으로 사용합니다.

1. Firebase 설정 상태

확인 중firebaseConfig 값을 확인하고 있습니다.

index.html에서 수정할 곳

아래와 같은 const firebaseConfig 부분에 Firebase 웹 앱 등록 화면에서 받은 값을 그대로 붙여넣으시면 됩니다.

const firebaseConfig = {
  apiKey: "여기에_apiKey_붙여넣기",
  authDomain: "여기에_authDomain_붙여넣기",
  projectId: "여기에_projectId_붙여넣기",
  storageBucket: "여기에_storageBucket_붙여넣기",
  messagingSenderId: "여기에_messagingSenderId_붙여넣기",
  appId: "여기에_appId_붙여넣기"
};

Firestore 보안 규칙

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}

2. 회원가입 / 로그인

로그인 상태아직 로그인하지 않았습니다.

3. 수동 동기화

저장 상태로컬 저장은 즉시 작동합니다. 로그인 후 Firestore 저장을 사용할 수 있습니다.

초보자용 다음 작업 순서

  1. Firebase 콘솔에서 Authentication → Sign-in method → Email/Password를 사용 설정합니다.
  2. Firestore Database를 생성합니다. 처음 테스트는 가까운 위치와 테스트 모드로 시작해도 되지만, 위 보안 규칙을 꼭 게시합니다.
  3. 이 파일의 const firebaseConfig 값만 실제 값으로 교체합니다.
  4. GitHub 저장소 web-test의 기존 index.html을 이 파일로 교체합니다.
  5. 주소 https://icookiekid.github.io/web-test/에서 회원가입 → 메모 저장 → 다른 기기 로그인 테스트를 합니다.
